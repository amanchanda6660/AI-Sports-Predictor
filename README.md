# AI Sports Predictor

AI Club project. We predict sports game outcomes with honest probabilities: when our model says a team has a 70% chance, that team should win about 7 out of every 10 games we say that about.

**New here? Start with [ONBOARDING.md](ONBOARDING.md).** It takes about 5 minutes, and you don't need to install anything.

## Team rules

Every change goes through a pull request (PR), and **Deandre or Adyant** approves it before it becomes part of `main`.

1. **Never change `main` directly.** Make a branch, then open a PR.
2. **Name branches `yourname/what-it-does`**, like `maya/intro` or `maya/calibration-chart`.
3. **Only edit files in your own area.** If you need to change someone else's file, ask them in the group chat first. This one rule prevents most merge conflicts.
4. **One PR does one thing.** Small PRs get reviewed in a day. Big ones sit.
5. **Get the latest `main` before you start new work** (see the bottom of [ONBOARDING.md](ONBOARDING.md)).
6. **Notebooks are personal.** Jupyter notebooks can't be merged cleanly, so put your name in the file name (`analysis/maya-market-odds.ipynb`) and never edit someone else's.
7. **Never upload passwords, API keys, or big data files.** Our code downloads the data.
8. **Don't reformat or "clean up" code you weren't asked to touch.** It creates conflicts for everyone else.
9. **Write commit messages that say what changed**, like "Add Maya intro", not "stuff" or "fix".
10. **If you see "merge conflict" or anything scary, stop and ask.** Don't delete things to make the error go away.
